# zenitstomatologia.pl · landing 1.0

Statyczna strona (HTML + CSS + JS bez bibliotek), kierunek A „Zieleń” wg `Materialy marki/strony-www/STRONY-WWW.md`.
Wdrożenie: osobny projekt Vercel `zenitstomatologia-strona` z Root Directory `strona/` (bez build command), domena zenitstomatologia.pl. Crux ma własny projekt i adres; strona do niego nie linkuje.

Przed publikacją uzupełnij pola oznaczone w kodzie klasą `todo` (przerywana ramka):
- numery ulic, godziny i telefony obu gabinetów (sekcja Gabinety i blok „Pierwsza wizyta”),
- cena pierwszej wizyty (FAQ) oraz ceny i czasy wizyt w kolorniku (`KOL` w skrypcie),
- nazwa podmiotu leczniczego i NIP w stopce,
- strony /regulamin i /polityka-prywatnosci (linki w stopce),
- obraz Open Graph 1200 × 630 (teraz ikona 512 px).
Plan leczenia w sekcji I ma kwoty przykładowe, podpisane na stronie jako „Przykład”.
