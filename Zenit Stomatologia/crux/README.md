# Crux

Wewnętrzny system sieci gabinetów zenit.stomatologia (wydanie 1.0 „Krasnodrzew”).

Wymaga Node 22 (`nvm use`) i pnpm 10 (`corepack enable`).

```bash
pnpm install && pnpm typecheck && pnpm lint && pnpm test
pnpm --filter @crux/web dev
```
